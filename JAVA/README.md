## Running an Example

Install a JDK, then run commands from this directory. For example:

```sh
mkdir -p out
javac -d out 01-Java-Foundation/01-Getting-Started/examples/first_code_in_java.java
java -cp out first_code_in_java
```

Compiled files go into `out/`, which is excluded from Git.
