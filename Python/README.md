# Python Learning & Practice

A comprehensive collection tracking the progression from foundational Python programming concepts to core data structures, modular function design, and competitive algorithmic problem solving.

---

## 🎯 Overview & Learning Flow

The Python curriculum is structured into three continuous stages:

1. **Syntax & Foundations**: Establishing basic programming fluency, user input handling, and control structures.
2. **Data Structures & Functions**: Mastering Python's rich built-in collection types, memory models, scope rules, and reusable function patterns.
3. **Algorithmic Problem Solving**: Applying foundational knowledge to solve competitive programming tasks, array problems, number theory challenges, and string validations.

---

## 📖 What Is Covered

### 1. Introduction & Core Syntax
This section focuses on essential language building blocks and execution flow:

- **Console Output**: Printing standard text and formatted output.
- **Variables & Data Types**: Working with integers, floating-point numbers, strings, and boolean values; inspecting types dynamically.
- **Terminal User Input**: Reading user input from the command line, performing type casting (e.g., converting strings to integers/floats), and performing arithmetic operations on input values.
- **Operators**: Exploring arithmetic operators (addition, subtraction, multiplication, division, floor division, modulo, and exponentiation) along with comparison operators.
- **Conditional Flow**: Directing program behavior using `if`, `elif`, and `else` branches with compound boolean expressions.
- **Loops & Iteration**:
  - `for` loops for iterating through ranges, sequences, and items.
  - `while` loops for continuous execution based on conditional criteria.

---

### 2. Built-in Data Structures & Intermediate Concepts
This section dives into data collections and modular code architecture:

- **Strings**:
  - Indexing and slicing techniques.
  - String immutability and built-in methods for formatting, searching, and case manipulation.
- **Lists**:
  - Mutable ordered sequences.
  - In-place modifications, item appending, extending, insertions, removals, popping, and sorting.
- **Tuples**:
  - Immutable ordered collections for fixed record representations.
  - Item counting, index lookups, and immutability guarantees.
- **Sets**:
  - Unordered collections enforcing unique elements.
  - Membership testing, deduplication, and set operations (union, intersection, difference).
- **Dictionaries**:
  - Associative key-value mapping.
  - Safe key lookups with `.get()`, dynamic value assignments, iteration over keys, values, and pairs.
- **Functions & Reusability**:
  - Defining custom functions with parameters and explicit return statements.
  - Returning multiple values packed as tuples.
  - Accepting arbitrary positional arguments (`*args`) and arbitrary keyword arguments (`**kwargs`).
- **Namespace & Scope**:
  - Distinguishing between local function namespaces and global module variables.
  - Modifying global state inside functions using the `global` keyword.
- **Modules**:
  - Importing and leveraging built-in Python modules (e.g., `math`) to extend program functionality.

---

### 3. Problem Solving & Algorithmic Practice
Practical coding challenges focusing on algorithmic thinking, mathematical logic, and edge-case validation:

- **String Format Validation**: Verifying that structured codes match exact formatting criteria and digit-character requirements.
- **Fibonacci Generation**: Iteratively calculating terms in the Fibonacci sequence.
- **Lucky Number Filtering**: Identifying numbers whose digits consist exclusively of specific numeric characters (e.g., digits 4 and 7) within a specified numerical range.
- **Number Palindromes**: Testing whether a number reads the same forwards and backwards, accompanied by reversed digit printing.
- **Array Min-Max Swapping**: Locating the boundary extreme values (minimum and maximum elements) within an array and interchanging their positions.
- **Smallest Pair Optimization**: Searching across all ordered pairs `(i, j)` in an array to minimize a dynamic mathematical formula.
- **Palindromic Array Symmetry**: Checking whether a sequence of elements is symmetric from both ends.
- **Digit Summation**: Processing large numeric strings to calculate the cumulative sum of all individual digits.

---

## 🚀 Execution & Practical Usage

- **Standard Execution**: Python scripts are run directly using standard `python3 <script_name>.py` commands.
- **Interactive Scripts**: Several scripts (especially problem-solving and input tasks) read data interactively from standard input.
- **No External Dependencies**: All exercises rely entirely on standard Python 3 built-in libraries and runtime capabilities.
