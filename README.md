# Programming Learning Repository

A dedicated, hands-on repository for mastering core programming concepts, data structures, and problem-solving across multiple modern programming languages.

---

## 🎯 What This Repository Is About

This repository documents a structured learning journey across three major programming ecosystems: **Java**, **JavaScript**, and **Python**. It focuses on building strong computer science fundamentals, progressing from initial syntax to intermediate data structures and competitive programming challenges.

---

## 🧭 Learning Tracks & Concepts

### ☕ Java
A foundational track focused on strongly-typed, object-oriented software development.

- **Foundations**:
  - Syntax structure and program execution.
  - Primitive data types, memory allocation, and variable declarations.
  - Arithmetic, logical operators, and explicit type casting.
  - Control flow logic using conditional statements (`if`, `else`, `switch`).
  - Iteration structures (`for`, `while`, `do-while` loops).
  - Terminal interaction and user input parsing via `Scanner`.
  - Modular programming with user-defined methods and parameter passing.
  - In-depth array operations, multidimensional arrays, and memory references.
  - String manipulation, immutability, and string utility methods.
- **Object-Oriented Programming (OOP)**:
  - Transitioning into class definitions, object instantiation, encapsulation, and class relationships.

---

### 🟨 JavaScript
A track covering the core building blocks of dynamic scripting and the web platform.

- **Variables & Scope**:
  - Declaration mechanics comparing `var`, `let`, and `const`.
  - Block scope, function scope, and hoisting behavior.
- **String Handling**:
  - String manipulation, concatenation, templating, and built-in string methods.

---

### 🐍 Python
A multi-stage track moving from fundamental syntax to Pythonic data structures and algorithmic problem-solving.

- **Core Syntax & Control Flow**:
  - Dynamic typing, variable declaration, and basic I/O operations.
  - Arithmetic and logical operations.
  - Decision making with conditionals.
  - Sequence traversal using `for` loops and condition-driven `while` loops.
- **Data Structures & Functions**:
  - Built-in collections: Lists, Tuples, Dictionaries, and Sets.
  - Function design, `*args`, `**kwargs`, multiple return values, and namespace scope management (`local` vs `global`).
  - Modular organization with Python imports.
- **Algorithmic Problem Solving**:
  - Solving contest-style problems covering string parsing, sequence generation, array traversal, and digit mathematics.

---

## 💡 Core Competencies Developed

1. **Comparative Language Understanding**: Contrasting statically typed languages (Java) with dynamically typed languages (Python, JavaScript).
2. **Data Structure Proficiency**: Choosing the appropriate data representation (lists, sets, maps/dictionaries, arrays) based on performance and use-case needs.
3. **Problem Solving & Logic Building**: Breaking down complex algorithmic problems into clean, efficient steps.

---

## ⚙️ How Code Is Executed

- **Python Scripts**: Executed via the Python 3 interpreter.
- **JavaScript Scripts**: Executed using a Node.js runtime environment.
- **Java Programs**: Compiled with `javac` into bytecode and executed using the Java Virtual Machine (`java`).
